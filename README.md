## 期限は3/12（木）～3/20（金）

## 要件・追加機能は以下

### CRUD操作を一通り機能として実装

- 食事情報の登録機能,NULL可,画像登録機能
- 栄養メモは登録後も編集可能
- 登録データは物理消去,論理削除　実装
- 追加した登録情報の編集

### JS機能実装

- 数秒後に画像が変わる機能
- 追加した情報や画像のレコードのドラッグ移動
- ページ内リンク
- 物理削除の際のダイアログ

### ＵＩ

- 初期画面(ログインページ)

- 管理者画面（論理削除したものがみれるページ/物理削除が可能なページ）
- 一般ユーザー画面（論理削除や登録など可能なページ）

- データ分析ページ(平均や中央値と比べた自身の食費のグラフやン1日あたりの食費の平均値を算出)
