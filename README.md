# 誰向けのアプリか

・アプリ概要：食事を管理し、振り返り計画を立てるためのアプリ
・ロールモデル：自分（男性/20代前半/ITエンジニア/リモートワーク）
・食費：月2~3万
・性格：向上心高め/自炊の抵抗がない/料理が趣味/仕事のパフォーマンスをあげたい
・一人暮らし

## 制作期間：3/12（木）～3/20（金）

- 初期画面(データ登録/データ一覧/消去済みデータなどを選択できる)

## 改善予定（一旦は保留すること）

### 優先度高め×すぐ出来る

- ER図もつくる

### 優先度高め×時間かかる

- API連携機能つける
- テーブルを5~10個にする(料理テーブル/目標テーブル/ユーザー情報テーブル/食材材料費メモテーブル)
- JOINや副問い合わせなどのSQL文も使用
- ログイン機能をつける
- 論理削除して30日たてば物理削除する自動削除機能実装

### 優先度低め×すぐ出来る

- SEO対策を考慮したタグ使用
- UX向上のため、JS用いてフロントエンド3割くらいさらにお洒落にする

### 優先度低め×時間かかる

- 大量データ登録時のページング機能つける(5pくらい)
- モチベ維持に役立つ機能実装(記録グラフ化/画像一覧をJS用いてお洒落に表示/よく使う食材の相場の値段を整理)
- アクセサビリティ向上のため、読み上げソフト使用時のことも考慮してHTMLタグを使用する
- これまでつくったご飯がプレビューになる機能をJSで実装しモチベ維持に繋がるようにした。
